# 更新紀錄

本文件以簡潔、可追溯的方式記錄系統與技術文件的變更。它不取代 Git history、Supabase migrations 或正式部署紀錄；每筆更新應盡量包含日期、變更範圍及對使用者／維運的影響。

## 1.0.0 — 首次正式上線

- 首次正式上線版本。
- 提供校內 Google OAuth 登入與角色導向的回報／管理流程。
- 使用 Supabase PostgreSQL 保存身分、回報快照及系統設定。
- 透過資料庫 RPC 與 RLS 執行回報寫入及資料存取限制。
- 使用 Upstash Redis 與 `@upstash/ratelimit` 為指定 API 提供使用者層級 rate limiting。

> 本版本是專案首次正式上線的版本基準，不表示所有後續規劃功能都已完成。
